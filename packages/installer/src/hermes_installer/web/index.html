Hermes Voice Satellite

Voice devices for Hermes · Satellite Gateway and device setup

    Bring Hermes into the room.

    Hermes Voice Satellite connects a microphone and speaker to Hermes, so you can speak a wake word, ask a question, and hear the answer.

    Start here to install the Satellite Gateway beside Hermes, add a satellite, or change an existing device. We will check what is available and show what will change before you approve it.

    You need Hermes already running on the computer that will host the Satellite Gateway. A separate computer preparing a device does not need Hermes.

    Choose what to set up

    Your task

    The Satellite Gateway is the voice service on your Hermes computer. A satellite is the microphone and speaker in a room.

    Checking this computer for Hermes…
    Hermes is not installed yet?

    Install Hermes on the Satellite Gateway computer using the official Hermes installation guide. Then return here. Device preparation can run on a different computer.

    Set up the Satellite Gateway

    This will install the Satellite Gateway on this computer. You must have Hermes already running here. This computer will stay on to answer your satellites.

    Use this computer's network address, not localhost. The Satellite Gateway listens for secure device connections and a separate pairing connection.

    Next, review the installation commands. Nothing is installed until you approve that review. Some steps may need administrator permission.

    Which satellite do you have?

    Device model

    Choose the board you are preparing. This selects the correct connection, software and wake-model format. No device is written at this step.

    Connect your satellite

    Continue checks the connection. On USB, it reads the board's identity so changes are sent to the device you selected.

    Find your Satellite Gateway

    Enter the address and pairing port from Satellite Gateway setup. We will read its identity code before sending any pairing words.

    The pairing port is not the device registry port. The Satellite Gateway setup record lists both.

    Check the Satellite Gateway's identity

    Does it match your saved code?

    Compare this code with the one you saved when you set up the Satellite Gateway. Matching codes protect your pairing words from being sent to the wrong computer.

    Pair this satellite

    The pairing words authorize this satellite to join the Satellite Gateway. It receives its own certificate and key; the words stay private.

    What can you change?

    This satellite keeps its existing pairing and firmware. Choose only the settings you want to replace; everything else stays as it is.

    The Satellite Gateway currently uses one voice for all satellites. Voice files and that shared selection are managed on its computer, not by changing a device's firmware.

    Choose the Wi-Fi network

    The satellite needs a network that can reach the Satellite Gateway. Leave the network blank to keep its current settings.

    The Wi-Fi password is used once: stored in a private temporary file, sent to the device, then deleted. It is not included in the command log.

    Choose the wake word

    Compare community measurements

    The satellite listens for this phrase before sending speech to Hermes. The default is hey hermes. Only compatible models are offered. Continuing downloads a selected third-party model to this computer for review; the device is not written until you approve.

    Your own files are always accepted, without catalogue measurements. Choose ONNX for a Pi or TFLite for an ESP32.

    Listen to a voice

    Voice catalogue

    Use a voice file on this computer

    Choose the Piper .onnx and its .onnx.json. Listen to a line made by this voice before installing it.

    Browse the Piper catalogue and listen before downloading a model. Both HFC sample clips play offline. Other models download only when you ask.

    Voice downloads are saved on this computer. The Satellite Gateway uses one shared voice, not one per device. Continue keeps the current voice. Selecting a downloaded voice affects a local Satellite Gateway only, after its next restart; this installer will not restart it.
